# Modern E-Commerce Website

A full-featured, modern e-commerce website built with Next.js, TypeScript, and Tailwind CSS.

## Features

- 🏠 **Homepage** - Hero banners, featured products, categories, flash sales
- 🛍️ **Product Pages** - Detailed product views with images, specs, reviews
- 🛒 **Shopping Cart** - Add/remove items, quantity management
- 💳 **Checkout** - Secure checkout with multiple payment options
- 👤 **User Authentication** - Login, signup, password reset
- 📱 **User Dashboard** - Orders, wishlist, saved addresses, profile
- 🔧 **Admin Panel** - Product management, order management, analytics
- 📱 **Mobile Responsive** - Fully optimized for all devices
- ⚡ **Fast Performance** - Optimized for speed and SEO

## Getting Started

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Tech Stack

- **Next.js 14** - React framework with SSR
- **TypeScript** - Type safety
- **Tailwind CSS** - Utility-first CSS
- **Zustand** - State management
- **Framer Motion** - Animations
